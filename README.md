# 🎂 Birthday Wishing Website 🎉

A creative and interactive Birthday Wishing Website designed to make a special birthday memorable through animations, memories, music, and a personal birthday surprise. 💖✨

---

## 🎉 Features

- 🎆 Birthday Celebration Animation
- ⏳ Countdown Effect
- 🚀 Fireworks Animation
- 🎥 Memory Video Slideshow
- 🖼️ Birthday Photos & Memories
- 🎁 Interactive Gift Box
- 💌 Personal Birthday Letter
- 🎵 Background Music
- ❤️ Special Birthday Wishes
- ✨ Smooth Animations & Transitions
- 📱 Mobile-Friendly Design

---

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🎥 HTML5 Video
- 🎵 HTML5 Audio
